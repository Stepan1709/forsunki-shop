# ADR 0002. Секреты в файлах, а не в переменных окружения

**Статус:** принято (этап 0)

## Решение
Пароли хранятся в файлах и монтируются Compose `secrets:` в `/run/secrets/<имя>`.
- Postgres и RabbitMQ читают их через `*_FILE`.
- Redis не умеет `*_FILE`: пароль подставляется командой запуска из файла.
- Приложение читает их через `pydantic-settings` (`secrets_dir`), имя поля = имя файла.
- Dev: `make secrets` создаёт случайные значения в `deploy/secrets/dev/` (в `.gitignore`).

## Почему
Переменные окружения видны в `docker inspect`, `/proc/<pid>/environ`, часто попадают в логи
и дампы падений. Файл в tmpfs виден только процессу в контейнере.

## Нюанс
Права файлов dev-секретов 644: контейнеры работают не от владельца файла. В prod права и владельца
задаёт администратор сервера, файлы вне репозитория.
