# ADR 0001. uv как менеджер пакетов, три независимых проекта

**Статус:** принято (этап 0)

## Контекст
Три сервиса (`api`, `web`, `payment_stub`) собираются в отдельные образы и ставят разные зависимости.

## Решение
- Менеджер пакетов **uv** (быстрый, `uv.lock` с хэшами, кэш в Docker через `--mount=type=cache`).
- У каждого сервиса свой `pyproject.toml` и `uv.lock`, **без** uv workspace.
- Общие только настройки Ruff (`ruff.toml` в корне, Ruff находит его сам).
- Python 3.12 зафиксирован в `.python-version` и `requires-python`.

## Почему
Workspace заставил бы собирать образы из общего lock-файла: любое изменение зависимостей `web`
пересобирало бы `api`. Независимые проекты проще в Docker и ближе к «настоящим» сервисам.
Цена: общий код между сервисами не импортируется, и это хорошо, так как связь идёт по HTTP и сообщениям.

## Альтернативы
Poetry (медленнее, хуже кэш в Docker), pip-tools (нет единого инструмента для окружения и Python).
